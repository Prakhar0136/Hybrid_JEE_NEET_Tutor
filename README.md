# Hybrid JEE/NEET Tutor

An AI-powered exam preparation platform using retrieval-augmented generation (RAG), NCERT-grounded answers, and adaptive assessments.

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: FastAPI
- Database: MongoDB
- AI: Sentence Transformers, FAISS, Cross-Encoder, Groq/Gemini APIs
